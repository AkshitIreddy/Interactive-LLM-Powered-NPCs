# Eclipse Harbor demo provenance

## Rights and source statement

Every visible element in this demo was authored for Interactive LLM Powered NPCs 2.0:

- **Eclipse Harbor** is a fictional setting created for this repository.
- **Mara Venn**, her biography fragments, dialogue, silhouette, portrait, costume, and facial features are original.
- The harbor skyline, breakwater, sea, beacons, UI chrome, icons, typography treatment, cursor choreography, subtitles, and performance HUD are generated from repository-owned HTML, CSS, SVG, and JavaScript in `demo/readme/scene/`.
- The Response Console presentation shares the application’s original Windows cybernetic design system: void `#090308`, wine `#12070D`, raised wine `#210A13`, structural coral `#FF4C5F`, deep coral `#B72A3E`, live/action cyan `#5FFBFF`, off-white `#F7F3F4`, muted red-grey `#BBA4AC`, clipped corners, hard rules, and Bahnschrift/Segoe UI system typography. It does not copy game UI artwork, fonts, logos, or textures.
- The demo contains no captured gameplay, extracted game asset, publisher logo, fan-wiki prose, performer likeness, cloned voice, music, or sound recording.
- The video is silent by design. Dialogue is represented with original on-screen text and a synthetic waveform.

## Production tooling

- Gifsmith 0.3.5 (MIT) supplies deterministic virtual-time capture, anchor-loop selection, and GIF/WebP/MP4 encoding orchestration.
- Chromium renders the single browser target.
- FFmpeg, supplied locally through the pinned `ffmpeg-static` package for this renderer, encodes the derived publication and review files.
- Segoe UI and system fallback fonts are requested; no font files are redistributed.

## Accuracy boundary

The scene is a deterministic product simulation. The latency, resource, confidence, and frame-impact values shown in its HUD are explicitly labelled **illustrative**. They are not measurements from a game, provider, model, GPU, or power profile.

The authoritative render metadata is `render-manifest.json`. Generated media may be recreated locally but must not be publicly hosted, pushed, released, or attached to a public update feed without explicit user approval.
