# Troubleshooting

Start with the page matching the failing stage:

- [Startup and game detection](startup-and-game-detection.md)
- [Audio and AI providers](audio-and-ai-providers.md)
- [Models and performance](models-and-performance.md)

Before changing settings, note the exact build, profile, execution/performance modes, and Response Spine stage. Run deterministic simulation: if it fails too, investigate runtime/configuration; if it passes, investigate device, provider, game, or display integration.

Export the narrowest diagnostic time range and preview it. Do not post credentials, dialogue, memory, recordings, webcam/capture frames, private paths, provider payloads, or proprietary game assets.

Use [SUPPORT.md](../../SUPPORT.md) for report fields and [SECURITY.md](../../SECURITY.md) for private vulnerabilities.
