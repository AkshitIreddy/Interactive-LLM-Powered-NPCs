# Models and performance

## Optional lip-sync pack download or install fails

Read the exact lifecycle state. Retry network interruptions; free disk space for disk-full; reject changed size/hash/signature/TUF metadata; remove only failed staging data; use Repair for an installed pack. Never bypass integrity or safe-extraction checks.

## Lip-sync pack will not activate

Check runtime ABI, platform/architecture/backend, driver, license acceptance, storage, attestation, self-test, and explicit user activation state. A default, dependency, migration, game/profile, or fallback cannot activate a pack. The previous active version should remain. Roll back rather than modifying pack files.

## Lip-sync pack runs out of memory

The game may have consumed the planned headroom. Close unrelated GPU workloads, reduce game texture/resolution settings if acceptable, select a lower-resource qualified lip-sync option, increase reserved headroom, or disable animation. The runtime does not change models or providers automatically; repeated failure quarantines the optional visual pack while audio/subtitles continue.

## Game FPS drops or latency rises

Switch to Competitive/Fast, inspect live CPU/GPU/VRAM/RAM and degradation reasons, disable continuous vision and screen-space animation, then compare a deterministic audio-only scenario. Do not change privacy/provider route implicitly.

Capture a reproducible trace with exact game scene/settings, power/boost state, driver, competing workloads, cold/warm state, and raw frame-time distribution. A laptop Silent-mode/shared-machine run is characterization only.

## Conversation or lip-sync quality is poor

For conversation, confirm the selected provider/model loadout, language, prompt/profile/spoiler tier, context budget, memory evidence, and whether an explicitly authorized route was changed. For visuals, confirm the exact lip-sync pack revision, capture/track confidence, and resource budget. A larger visual model is not automatically safer under game load. Report a fictional/minimal reproduction rather than copyrighted dialogue.
