# Game content, voice, and profile policy

This is a project contribution/distribution policy, not legal advice.

## Allowed by default

- Original profile prose, prompts, fictional examples, and synthetic fixtures created for this project.
- Small factual identifiers needed for interoperability—game/executable/store names and build metadata—used nominatively.
- User-authored character/personality material they have the right to use.
- Links/references to official public interoperability documentation without bundling restricted files.
- Assets/components with verified compatible licenses and recorded provenance.

## Not accepted

- Copied wiki/guide prose, extracted game scripts, dialogue dumps, images, video, music, sound effects, voice lines, textures, meshes, fonts, or logos without explicit compatible rights.
- Voice cloning or intentional imitation of an actor/performer from game audio without documented rights and consent.
- Model/data artifacts whose terms forbid the intended use or redistribution.
- Anti-cheat/DRM/protected-mode bypasses, online automation, or instructions to evade safeguards.
- Executable code hidden in profile data, arbitrary download/install hooks, credentials, pickles, or unverified binaries.
- Misleading affiliation/endorsement claims.

## Provenance requirements

Record creator/source, creation method/tool, license/version, attribution, modification notes, file hash, and redistribution/use restrictions for profile content and assets. If rights are unclear, exclude the material.

Generated material is not automatically safe: prompts, references, likenesses, voices, trademarks, and model terms still matter. Synthetic demos must use fictional games, characters, UI, dialogue, telemetry, and owned/compatible fonts/assets.

## Game integration boundary

Built-in and community profiles are data-only. The project does not accept or distribute per-game mods, script extenders, hooks, injected DLLs, executable adapters, or native-rig integrations. Supported interaction stays outside the game through Windows capture, overlay, hotkeys, audio, subtitles, and manual/read-only screen-based selection. Protected, online, anti-cheat, or ambiguous configurations are refused rather than bypassed.

## Trademarks and affiliation

Game names identify compatibility targets only. This project is not affiliated with or endorsed by game publishers/developers unless documented otherwise. Avoid official trade dress and use plain text names where possible.
