# Original interface art

Generated with the built-in OpenAI image tool on 2026-09-08 for this project.
No game screenshots, logos or proprietary fonts are incorporated in these files.

- `neural-anatomy.png`: original synthetic anatomical figure, graphite and bone,
  red nerve threads and cyan signals on a dark background. Used as decorative
  model-loadout anatomy; interactive controls are separate HTML elements.
- `city-afterhours.png`: original invented rain-soaked futuristic megacity banner.
  Atmospheric decoration, not a screenshot or claim of a running game.

User Cyberpunk screenshots supplied the palette/density inspiration and remain
outside the repository under the project's private design-reference directory.
